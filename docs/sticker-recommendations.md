# SVG 스티커 추천 연결

근거 문서: `classcification/스티커 분류 기준-개발.docx`, `스티커 분류 기준-디자인.docx`, `스티커 디자인 분류 기준.docx`.

현재 사진 분석/8개 건물 분류 흐름에 규칙 기반 SVG 추천을 연결했다. 문서의 전체 MVP(사진 2장, 실측, 견적, 구매)를 구현한 것은 아니다.

## 데이터와 흐름

- 원본: `components/*.svg`의 48개 파일, 6계열/8형태/6색. 원본 경로·색상을 보존한다.
- `npm run stickers:build`: 원본을 `src/data/sticker-assets.json`에 색인한다. dev/build 시작 시 자동 실행된다. 파일을 추가하면 스크립트의 이름 매핑도 확인한다.
- `src/config/sticker-catalog.ts`: 모티프·색상·공간 용도·가중치 설정.
- `src/lib/recommend-stickers.ts`: 건물 분류, 반사·식생·위험도, 사용자 확인값으로 후보를 필터링/점수화하여 서로 다른 계열의 조화형·미니멀형·시그니처형을 반환한다.
- 사용자가 지정한 공간 용도를 우선하며 미지정 시 건물 분류를 기본 기준으로 사용한다. 현재 AI JSON에 없는 외벽 재질·색조·기하형태·복잡도는 사용자 입력으로 보완한다. 통유리 분류의 격자형은 기본 추천 가정이다.
- 현재 원본에 없는 잎·연결 노드 등은 생성하지 않는다. 교육시설 등은 전달된 씨앗·마름모·원 계열로 대체한다. 이 매핑과 가중치는 문서를 현재 자산에 적용한 구현 판단이며 디자인팀 승인 데이터는 아니다.
- 강한 식생 환경은 녹색, 강한 하늘 반사는 하늘색을 제외한다. 제공된 회색은 밝은 회색이며 차콜로 취급하지 않는다. 실제 원본의 아이보리·갈색을 밝기 대비용으로 함께 사용한다.
- 외벽 재질에 따라 마감 방향을 제안한다. 제품 호환성/판매 가능성이 검증됐다는 의미는 아니다.
- 추천 조건 변경 시 첫 추천으로 선택을 초기화한다. 선택된 레시피는 `/api/generate`에서 동일 규칙으로 재검증한 후 SVG로 조립한다. 잘못된 레시피 ID는 400 응답이다.
- 미리보기와 다운로드가 같은 SVG 반복 렌더러를 사용한다. 다운로드는 외부 파일 참조 없는 SVG이다. 이 경로는 Gemini 이미지 생성 API와 데모 고정 스티커를 사용하지 않는다. 기존 이미지 생성 유틸리티/프롬프트는 미사용 상태로 남아 있다.

## 현재 범위와 검수 상태

전달된 파일에는 승인 배열·실제 치수·선 두께·생산 상품·검수 메타데이터가 없다. 모든 레시피는 `safetyValidated: false`, `productionReady: false`이며 디자인 미리보기만 제공한다. 문서에서 요구하는 생산용 안전 필터를 통과했다고 간주하지 않는다.

반복 간격은 화면 상대 단위이며 5×10cm 또는 5×5cm 실제 배열을 보증하지 않는다. 미니멀형도 다른 추천과 같은 반복 간격을 사용한다. 유리 영역으로 클리핑하지만 원근 보정/물리 단위 환산은 아직 없다. 치수 입력, 검수 완료 레시피, 상품·가격 데이터가 확보되어야 생산용 출력과 견적을 추가할 수 있다.

## 확인

`npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.
추천 테스트는 원본 일치, 분류별 3계열 다양성, 용도 보정, 반사 환경 색상 제외, 재질 마감, 반복 간격 유지, 선택한 SVG 다운로드 및 잘못된 요청 거부를 확인한다.
